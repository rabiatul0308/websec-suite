2. Daftar Temuan Kerentanan & Rekomendasi

MEDIUM [Web App] Security Headers — Missing Content-Security-Policy (CSP)

Bukti Teknis: Header CSP tidak ditemukan; meningkatkan risiko XSS dan injeksi skrip eksternal.

Rekomendasi Perbaikan: Tambahkan header Content-Security-Policy (mis. default-src 'self').

MEDIUM [Web App] Security Headers — Missing X-Frame-Options (Clickjacking Risk)

Bukti Teknis: Halaman dapat dimuat di dalam <iframe> lintas domain.

Rekomendasi Perbaikan: Set header X-Frame-Options: DENY atau SAMEORIGIN.

LOW [Web App] Security Headers — Missing X-Content-Type-Options

Bukti Teknis: Browser berpotensi melakukan MIME-sniffing.

Rekomendasi Perbaikan: Set header X-Content-Type-Options: nosniff.

LOW [Web App] Security Headers — Missing Referrer-Policy

Bukti Teknis: URL sensitif beserta parameter query berisiko bocor melalui header Referer ke pihak ketiga.

Rekomendasi Perbaikan: Set header Referrer-Policy: strict-origin-when-cross-origin.

MEDIUM [Server Infra] SSL/TLS & Transport — Missing HTTP Strict Transport Security (HSTS)

Bukti Teknis: Koneksi HTTPS tidak menyertakan header Strict-Transport-Security.

Rekomendasi Perbaikan: Aktifkan Strict-Transport-Security: max-age=31536000; includeSubDomains; preload.

LOW [Server Infra] Versi OS & Perangkat Lunak — Runtime / Backend Framework Version Disclosure

Bukti Teknis: Header X-Powered-By membocorkan runtime: 'Next.js'.

Rekomendasi Perbaikan: Nonaktifkan header X-Powered-By dan perbarui runtime ke rilis LTS terbaru.
